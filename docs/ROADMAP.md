# Roadmap

Deferred from v0.1 on purpose. Each item was discussed; none is forgotten.

- Articles editor (`type: ARTICLE`, title, long-form body).
- Post queue manager (reschedule, spacing, send now for queued posts).
- "Share to Tinkerer" from a thread (composer plus-menu / message action)
  and "Draft with bb" AI drafting inside the Composer.
- Session post after finishing a lock-in.
- Marketplace, gear, skills and prompts publishing.
- Events RSVP UI, friend requests, spark gifting.
- Full topic tree navigation beside the feed.
- SQLite snapshot cache for instant, offline-readable panel opens.
- iOS and Raycast clients.
